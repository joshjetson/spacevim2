SpaceVim2 · exclusive

A terminal you edit
like a Vim buffer

Open a shell with SPC '. It's an ordinary buffer — and its command line takes real Vim keys.

Default

Type

Every keystroke goes straight to the shell, exactly like a normal terminal.

Press Esc

Navigate

Vim's normal mode, over the live command line — move by word, delete, select, copy — then drop back into typing right where you were.

Navigate mode
Move & resume typing
bwe0$fthe usual Vim motions across the command line
i/aresume typing before / after the character under the cursor
I/Aresume typing at the start / end of the line
Delete
xdelete the character under the cursor
dw/dbdelete a word forward / backward
Ddelete from the cursor to the end of the line
dd·2dddelete this line · several — of a multi-line command
Select & copy
v…dvisually select a range, then delete the highlight
yyank — copy a URL, a path, or a chunk of output
Paste never runs by accident

P (in Navigate) or Ctrl-V (while typing) drops your last yank onto the prompt without executing it — and a multi-line paste arrives as one command to review, not a burst of auto-run lines.
